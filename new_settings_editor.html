ตั้งค่าระบบกลาง

รวมข้อมูลที่ผู้ใช้ต้องตั้งค่าบ่อยไว้ในหน้าเดียว แยกส่วนข้อมูลทั่วไป งานพิมพ์เอกสาร และการเปลี่ยนปีการศึกษาให้ชัดเจน

บันทึกได้ทันที โดยยังคง logic เดิมของระบบ

ยังไม่ตั้งค่า
ดูจากโฟลเดอร์บันทึก PDF
ข้อมูลทั่วไปของโรงเรียน
ส่วนที่ผู้ใช้แก้ไขบ่อยที่สุด เช่น ชื่อโรงเรียน ปีการศึกษา และผู้บริหาร
จัดกลุ่มข้อมูลให้กรอกง่ายขึ้น โดยแยกข้อมูลโรงเรียนและข้อมูลผู้บริหารไว้ในบล็อกเดียว
ใช้ในเอกสารที่เกี่ยวกับการรับรองผลการเรียนและงานวิชาการ
การพิมพ์เอกสารและไฟล์ PDF
ตั้งค่าโลโก้และโฟลเดอร์ปลายทางสำหรับเอกสารที่ระบบสร้าง
ขั้นตอนที่ 1
ตั้งค่าเพียงครั้งเดียว แล้วระบบจะนำไปใช้กับรายงาน PDF และเอกสารอื่นอัตโนมัติ
พรีวิวโลโก้จากรหัสไฟล์ Google Drive
วางเฉพาะ File ID ของรูปโลโก้ ระบบจะพยายามโหลดรูปให้อัตโนมัติ
ใช้เป็นปลายทางเก็บไฟล์ PDF ทั้งหมดจากระบบ เพื่อให้ค้นหาไฟล์ย้อนหลังได้ง่าย
เปลี่ยนปีการศึกษา
ส่วนนี้เป็นงานระดับระบบ ควรตรวจข้อมูลก่อนกดทำจริงทุกครั้ง
ขั้นตอนที่ 2
ระบบจะสำรองไฟล์ สร้าง snapshot ของชีตสำคัญ และเตรียมข้อมูลปีใหม่ โดยข้อมูลเดิมยังคงอยู่ในรูปแบบที่ย้อนดูได้
แนะนำให้กด “ดูข้อมูลก่อนเปลี่ยน” เพื่อตรวจสอบผลกระทบก่อนดำเนินการ
บันทึกการตั้งค่าทั้งหมด
อัปเดตข้อมูลโรงเรียน บุคลากร โลโก้ และปลายทาง PDF พร้อมล้าง cache ให้ระบบใช้งานค่าล่าสุดทันที
