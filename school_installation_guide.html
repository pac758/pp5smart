คู่มือการติดตั้งและเริ่มใช้งานระบบบริหารจัดการสถานศึกษา

สำหรับโรงเรียนปลายทาง (ฉบับย่อใช้งานจริง)

1) วัตถุประสงค์

เอกสารนี้จัดทำเพื่อให้โรงเรียนสามารถติดตั้งระบบและเริ่มใช้งานได้อย่างถูกต้อง ลดปัญหาในขั้นตอนการตั้งค่าครั้งแรก และตรวจสอบความพร้อมก่อนเปิดใช้จริง

2) สิ่งที่ต้องเตรียม

  • บัญชี Google สำหรับผู้ดูแลระบบ
  • สิทธิ์ใช้งาน Google Sheets และ Google Apps Script
  • ผู้รับผิดชอบติดตั้งอย่างน้อย 1 คน (แนะนำ 2 คน: หลัก/สำรอง)

3) ขั้นตอนติดตั้ง

  1. เปิดลิงก์ Template Spreadsheet ที่ได้รับ แล้วเลือก File → Make a copy
  2. เปิด Extensions → Apps Script
  3. เลือกฟังก์ชัน debugSetupStatus แล้วกด Run เพื่อ Authorize ครั้งแรก
  4. ไปที่ Deploy → New deployment → Web app
  5. กำหนดค่า Execute as: Me และ Who has access ตามนโยบายโรงเรียน
  6. กด Deploy แล้วคัดลอก URL
  7. เปิด URL ระบบ เข้า Setup Wizard และวาง URL ของ Spreadsheet สำเนา
  8. กรอกข้อมูลโรงเรียนให้ครบ แล้วบันทึก
เหตุผลที่ต้องรัน debugSetupStatus ครั้งแรก
  • เพื่ออนุญาตสิทธิ์ให้ Script เข้าถึง Spreadsheet / Properties / Drive
  • เพื่อตรวจสอบความพร้อมของระบบก่อนเปิด Web App
  • ลดโอกาสเกิดข้อผิดพลาดสิทธิ์ไม่พอระหว่าง Setup Wizard

4) Checklist ก่อนเปิดใช้งานจริง

  • เข้า Dashboard ได้ตามปกติ
  • บันทึกหน้า "ตั้งค่าระบบ" ได้
  • เพิ่ม/แก้ไขข้อมูลนักเรียนได้
  • ทดสอบออกรายงาน PDF อย่างน้อย 1 รายงานได้
  • ครูผู้ใช้งานเข้าเมนูหลักตามสิทธิ์ได้

5) ปัญหาที่พบบ่อย

  • เปิดระบบแล้วแจ้งสิทธิ์ไม่พอ → กลับไปรัน debugSetupStatus และ Authorize ใหม่
  • บันทึกแล้วข้อมูลไม่อัปเดต → รีเฟรชหน้า (Ctrl+F5) และตรวจว่าใช้ URL deployment ล่าสุด
  • ผู้ใช้บางคนเข้าไม่ได้ → ตรวจค่า Who has access ใน Deployment
เอกสารนี้ใช้สำหรับส่งมอบระบบให้โรงเรียนปลายทาง สามารถพิมพ์หรือส่งต่อเป็น PDF ได้ทันที
